# 導線走線大師

LIS 情境科學教材「晶片系列 EP4：晶片的誕生」課堂結尾活動。

學生跟著晶片小八回到 1958 年，幫基爾比和諾伊斯解決難題，接導線、蓋立體電路、收集零件，最後親手組裝一顆晶片。

## 上課使用

- **學生自己玩**：https://pxchen-89.github.io/chip-ep4/ ，掃 QR code 或打開網址就能開始，不用登入、不用安裝。這個模式不記錄任何資料。
- **全班即時競賽**：老師打開 https://pxchen-89.github.io/chip-ep4/teacher.html ，按「開新的一場」，投影房間代碼與 QR code。學生加入後等老師按開始，投影幕即時顯示排行榜，結束時有頒獎台。可以看各題第一次答對的情況，也可以下載 Excel 成績。

## 想修改遊戲

1. 改 `src/` 裡的原始檔，不要直接改根目錄的 `index.html`、`teacher.html`。
2. 在專案根目錄執行 `python build.py`，組出新的 `index.html`、`teacher.html`。
3. 推上 GitHub，網站約 1 分鐘內自動更新。

完整的檔案說明、測試方法、要同步修改的地方與教學設計原則，寫在 [CLAUDE.md](CLAUDE.md)。用 Claude Code 打開這個專案時，它會自動讀這份說明。

## 資料與安全

- 即時競賽用 Firebase（匿名登入＋Firestore）暫存學生輸入的名字、班級、遊戲進度與每題第一次的作答。老師可以在頒獎台按「刪除這場的資料」清除。
- 安全規則見 `firestore.rules`：學生只能改自己的資料，作答紀錄只有開房的老師讀得到，只有開房的老師能開始、結束或刪除房間。
