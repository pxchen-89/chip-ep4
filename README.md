# 導線走線大師

LIS 情境科學教材「晶片系列 EP4：晶片的誕生」課堂結尾活動。

學生跟著晶片小八回到 1958 年，幫基爾比和諾伊斯解決難題，接導線、蓋立體電路、收集零件，最後親手組裝一顆晶片。

## 兩種玩法

- **自己玩**：https://pxchen-89.github.io/chip-ep4/ ，學生掃 QR code 或打開網址就能開始。
- **全班即時競賽**：老師打開 https://pxchen-89.github.io/chip-ep4/teacher.html ，按「開新的一場」，投影房間代碼與 QR code。學生加入後等老師按開始，投影幕即時顯示排行榜，結束時有頒獎台。

## 資料

- 自己玩：不記錄、不上傳任何資料。
- 即時競賽：用 Firebase（匿名登入＋Firestore）暫存學生輸入的名字、班級與遊戲進度。老師可以在頒獎台按「刪除這場的資料」清除。
- 安全規則見 `firestore.rules`：學生只能改自己的進度，只有開房的老師能開始、結束或刪除房間。
